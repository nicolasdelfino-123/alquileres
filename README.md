# Alquileres

Base del proyecto para gestión de alquileres.

## Estructura inicial

- Backend en Flask (estructura limpia y preparada para crecer)
- Frontend (vacío, listo para React u otro framework)

## Primeros pasos

1. Crea tu base de datos PostgreSQL y configura el archivo `.env` en `backend/` con tus credenciales.
2. Activa el entorno virtual y ejecuta las migraciones.
3. Levanta el servidor Flask y prueba el endpoint `/api/properties`.
